This repository is a portfolio of all projects undertaken by Fahim Ahmed, intern at Chinotech International during Summer 2025.

Portfolio Overview:

1- Real-time Fall Detection System: A robust system that detects human falls in real-time using pose estimation, alerting for potential emergencies.The key technologies used include Yolov8-Pose, Python, and OpenCV.

2- Custom Object Detection on Hailo-8: An optimized application built on the Hailo SDK for performing object detection and head count on the Hailo-8 AI accelerator. The key technologies used include HailoSDK pipeline, OpenCV, and Python.

3- Industrial Panel LED State Detection A computer vision solution to automatically detect and classify the state (ON/OFF) of LEDs on industrial equipment.The key technologies used include OpenCV, Python, and image processing.

The main repository serves as an overview. Each project has its own directory with detailed documentation including the full source code and dedicated README files.
